# 전문 편집 기능 현황

2026-09-28. 사용자는 조사한 Lightroom 기능을 개발 대상으로 지정했고, **기기 안에서만 처리하며 서버가 필요한 기능은 폐기**하도록 명시했습니다.

## 구현 및 엔진 검증

- [x] RAW 현상: 실제 켈빈 WB, 현상 톤/그림자 및 파일별 지원 노이즈·복구 옵션. RAW 저장 시 16비트 PNG 선택
- [x] 자동 톤·화이트밸런스·스포이트
- [x] RGB 히스토그램·SDR 초과/암부 비율·사진/화면 HDR 범위·SDR 클리핑 경고·원본 해상도 영역 확인
- [x] RGB 채널별 포인트 커브·컬러 그레이딩·기본 룩
- [x] 텍스처·안개·입자·정밀 선명도·일반/색 노이즈 감소
- [x] 브러시 누적·빼기, 선형·방사형·색·밝기 범위 마스크
- [x] 피사체·배경·iOS 27 탭 선택의 UI/API 연결, 선택 표시·반전·부분 보정
- [x] 요소 지우기 전용 화면: 1–8× 확대·이동, 칠하기/선택 지우기/획 취소/비우기, 실행·취소. 기존 복제·힐링 기록은 재생하되 신규 UI는 제거
- [x] 자르기 직접 조작·수동 원근·수동 왜곡·색 번짐 완화
- [x] SDR→HDR 밝기 지도 예측, 모델 실행 검증 및 CPU 재시도, 중간톤 보호, 강도·최대 배율, SDR 비교, 저장·undo/redo
- [x] HDR gain map JPEG/HEIC·TIFF·원본·사용자 크기·워터마크
- [x] 다중 가져오기·선택·일괄 보정·형식을 선택하는 일괄 출력
- [x] 앨범·별점·선별·휴지통·버전·Velyn 프리셋 교환
- [x] 카메라 촬영·수동 노출/초점·지원 기기의 RAW 경로. 실촬영 미검증
- [x] AOT-GAN 로컬 제거: 선택 영역의 crop을 512×512로 추론, 선택 밖은 기존 사진 사용
- [x] Depth Anything V2 Small 로컬 깊이 추정·초점 범위별 흐림

체크 표시는 코드/UI가 연결되었다는 뜻입니다. 자동 테스트는 합성 표본이며 사진 품질이나 실기기 수락 완료를 뜻하지 않습니다. Vision 피사체·탭 선택의 실제 사진/모델 상태 검증도 남아 있습니다.

## 제외된 서버 기능

클라우드 동기화·온라인 갤러리·공동 편집·Firefly 서버 제거/확장·서버 기반 생성은 포함하지 않습니다. 앱에 사진을 업로드하는 대체 경로도 없습니다.

## 아직 제공하지 않는 기능

| 기능 | 현재 경계 |
| --- | --- |
| 생성형 사진 확장 | UI/엔진 없음. 로컬 제거 모델이 외곽 확장 품질을 보장하지 않으므로 동일 기능으로 취급하지 않음 |
| AI RAW 디노이즈·초해상도 | 일반 공간/색 노이즈 감소만 제공. 검증된 RAW 모델·타일 처리·실사진 품질 회귀가 필요 |
| 자동 렌즈 프로파일/색수차/수평 분석 | 수동 근사 보정만 제공. 카메라/렌즈별 보정 DB 없음 |
| 인물 피부·눈·치아 세부 분할 | 피사체/탭 선택으로 지정 가능하나 의미별 자동 분류 없음 |
| 마스크 교집합·AI 적응형 프리셋 | 브러시 누적/빼기·반전은 지원. 다른 마스크 간 boolean 조합 없음 |
| Lightroom XMP/DCP | Velyn JSON 프리셋만 지원 |
| HDR 다중 노출 병합·파노라마·테더 촬영 | 구현하지 않음. 단일 사진 HDR 편집과 별도 기능 |
| 인쇄 전용 색 관리 | OS 공유 대상만 사용. 소프트 프루프·프린터 ICC·전용 인쇄 UI 없음 |
| 앨범 폴더·중복 검색·메타데이터 편집 | 기본 로컬 앨범/별점/분류 검색만 지원 |

이 항목들을 기기에서 불가능하다고 판정한 것은 아닙니다. **현재 구현되지 않은 항목**으로 남겨 두며, Lightroom 전체 기능이 완성되었다고 주장하지 않습니다.

## 남은 수락 검증

개발 팀 서명 후 실제 iPhone에서 12/48MP ProRAW, 카메라 RAW/ProRAW, 탭 모델 다운로드/오프라인 재실행, 머리카락·반사·반복 무늬 마스크/제거, Display P3/HDR 화면, 권한 거부·취소, 장시간 메모리/발열을 확인해야 합니다. 기획서 C01–C10 전체 완료로 표시하지 않습니다.
