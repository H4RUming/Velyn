새 지도는 강도 100%, 최대 5배, 중간톤 보호 끔, bilinear 보간을 기본으로 사용합니다.

[앱 연결 검증과 남은 실기기 확인](Evidence/hdr-camera-integration.md)을 참조하세요.

추가 학습했습니다. 반복 비교 132장의 평균 오차는 기존 GMNet 0.488 EV,
자체 모델 0.350 EV, 튜닝한 GMNet 0.328 EV입니다. 기존 중간톤 보호·강도를 적용하면
이점이 줄어 모델과 후처리를 함께 검증해야 합니다. 앱 기본 모델은 유지했습니다.
서버의 개인 작업 폴더는 결과 회수 및 해시 검증 후 전체 삭제했습니다.
[실험 및 한계](Evidence/hdr-gmnet-finetune-verification.md)를 참조하세요.

2026-10-02 사용자 승인 사진으로 추가 학습: HDR/SDR 882쌍을 확보해 618/132/132장으로

개별 사진 회귀와 실기기 검증이 남아 기본 모델을 교체하지 않았습니다.
이번 자료의 감광은 드물며, 감광 예측 자체를 HDR의 필수 조건으로 취급하지 않습니다.
모델을 Mac으로 회수한 뒤 서버의 개인 자료·가중치·로그가 든 임시 폴더 전체를 삭제했습니다.
[학습·평가·삭제 확인](Evidence/hdr-private-camera-verification.md)을 참조하세요.

2026-10-01 자체 모델 첫 학습: 공개 CC0 HDR 431개 원본에서 만든 합성 데이터로

2026-10-01 감광 모델 실험: 음수 EV 게인맵의 저장·렌더링·편집 기록과 감광 한도를 추가했습니다.

기본 GMNet은 계속 밝히기만 예측합니다. 감광 위주 결과에서 시스템 인코더가 게인맵을 생략하면
HDR 저장 성공으로 처리하지 않습니다. [실험과 한계](Evidence/hdr-signed-model-verification.md)를 참조하세요.

## 제외된 서버 기능

클라우드 동기화·온라인 갤러리·공동 편집·Firefly 서버 제거/확장·서버 기반 생성은 포함하지 않습니다. 앱에 사진을 업로드하는 대체 경로도 없습니다.
