# 사진 라이브러리 UI 개편

2026-09-28 · 사용자 요청: Lightroom 같은 사진 도구의 화면 구성으로 전면 개편.

## 화면

- 상단: 작은 Velyn 이름, 파일명 검색, 설정.
- 라이브러리: 사진 형식 필터, 사진 수, 정렬, 2열·3열 이미지 그리드.
- 빈 상태: 짧은 안내와 사진 추가 버튼.
- 하단: 라이브러리 상태와 항상 접근 가능한 사진 추가.
- 사진 보기: 검은 캔버스, 두 손가락 확대·이동, 두 번 탭 확대, 화면 맞춤.
- 정보: 파일 정보와 원본 보관 상태. SHA-256·디코더는 접힌 상세 항목.
- 설정: 로컬 보관·백업 제외·개인정보 안내.

소개용 슬로건, 세리프 로고, 초록색 강조, 큰 장식 카드, 개발 단계 표시를 제거했습니다. 연결되지 않은 편집 버튼은 추가하지 않았습니다.

## 구현

`ContentView`는 라이브러리 상태와 탐색을 담당합니다. `Features/Library`에 썸네일·사진 보기·정보·설정을 분리했습니다. 검색과 필터는 실제 가져온 항목에 적용합니다. 정렬·열 수는 기기에 저장합니다.

`OriginalImportService.preview`가 별도 actor에서 ImageIO 미리보기를 생성합니다. EXIF 방향을 적용하고 최대 2048px로 제한합니다. 그리드는 480px를 요청하며, NSCache의 cost limit은 32MiB입니다. 탐색용 미리보기이며 출력·RAW 기본 현상 계약을 대체하지 않습니다. 저장한 원본이나 manifest는 바꾸지 않습니다.

현재 UI 개편 요청을 근거로 기존 첫 단계의 메타데이터 화면에서 사진 탐색용 프리뷰까지 확장했습니다. M1-02의 RAW 디코더 선택·색 관리·정식 현상 검증은 여전히 남아 있습니다.

## 확인

- `./Scripts/verify.sh`: 테스트 12개 통과, iOS 시뮬레이터 빌드 성공.
- 새 검증: 방향 6 JPEG의 미리보기 크기, RAW 미리보기 해상도 제한, 미리보기 생성 뒤 원본 해시 유지.
- 시뮬레이터 시작 화면을 확인하고 `Evidence/library-redesign.png`에 저장.
- 이번 작업에서 사용자 사진이나 가짜 사진 목록을 앱에 추가하지 않음.
