# 사진 추가 경로

2026-09-29. 메인 화면의 사진 추가 버튼은 최근 사진을 고르는 하단 시트를 엽니다.

- 3열 최근 사진 격자, 선택 순서와 개수, 한 번에 최대 100장 선택.
- 시트를 위로 확장할 수 있으며 **앨범·전체 보기**는 시스템 사진 선택기를 엽니다.
- **파일**과 **카메라**는 시트를 닫은 뒤 해당 화면으로 이어집니다.
- 첫 접근은 설명과 허용 버튼을 표시합니다. 파일 가져오기는 사진 권한 없이 가능합니다.
- 제한된 접근에서는 허용한 사진만 표시하고 **선택 범위 변경**을 제공합니다.

## 지원 형식

RAW(DNG 등 설치된 디코더가 지원하는 형식), JPEG, HEIC/HEIF, PNG, WebP, TIFF, GIF, BMP, AVIF, JPEG XL, JPEG 2000.
선택기와 PhotoKit 원본 선택은 같은 형식 정책을 사용합니다. 확장자를 신뢰하지 않고 ImageIO가 감지한 실제 형식을 확인합니다. OS 디코더가 읽지 못하는 파일은 오류로 안내합니다.

애니메이션과 여러 페이지 이미지는 대표 장면 한 장을 편집합니다. 원본 바이트는 그대로 보관하며 원본 내보내기는 모든 프레임·메타데이터를 유지합니다. PNG 등의 투명 채널은 가져오기와 편집에서 유지합니다.

## 원본 및 권한

PhotoKit의 `.photo`·`.alternatePhoto` 중 RAW를 우선합니다. RAW가 없으면 지원 형식의 기본 원본을 선택합니다. 편집된 `.fullSizePhoto`, 썸네일, Live Photo의 동영상은 가져오지 않습니다.

원본 데이터는 PhotoKit 콜백에서 임시 파일로 스트리밍한 뒤 기존 actor에서 SHA-256 검증과 원자 저장을 거칩니다. 재인코딩하지 않습니다. 사진 보관함은 수정하지 않습니다. 취소와 늦은 콜백은 기존 원본 보존 규칙을 따릅니다.

PhotoBrowserService actor가 최근 항목을 페이지 단위로 조회하고 320px 썸네일을 요청합니다. 썸네일과 원본 요청 모두 네트워크 접근을 끕니다. iCloud 전용 원본은 사진 앱에서 먼저 다운로드해야 합니다. 시스템 파일 공급자 다운로드는 별도 시스템 동작입니다.

## 검증

[형식·선택·출력 검증](Evidence/image-formats-verification.md)을 참조하세요. 실제 iPhone에서 권한 거부·제한된 접근 변경, iCloud 전용 원본과 실제 ProRAW 가져오기는 계속 검증해야 합니다.

시뮬레이터 Debug 전용: `--import-source-smoke-test`로 시트를 열고 `--import-source-smoke-select`로 앞의 합성 사진 3장을 선택 상태로 표시합니다. 개인 사진이 없는 전용 시뮬레이터에서만 사용합니다.
