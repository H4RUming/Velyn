# v1.2.0 release verification

2026-10-02. Version **1.2.0**, build **5**, Xcode 27 / iPhoneOS 27 SDK.
Public bundle ID: `com.h4ruming.velyn`. Minimum OS: iOS 27.0; iPhone arm64.

## Builds and package

- The current engine passed `./Scripts/verify.sh`: **83 tests in 12 suites**, plus
  the iOS Simulator build. The subsequent release preparation changes version
  metadata and documentation, not the tested engine.
- Signed Release build succeeded using the existing ignored local signing
  configuration, followed by `./Scripts/package-release.sh 1.2.0` for the public
  unsigned archive. Both only warned about unused App Intents metadata extraction.
- ZIP integrity passed. All **55 entries** are inside `Payload/`, with no traversal
  paths, personal provisioning profile, app signature directory or signing keys.
- Packaged Info.plist confirms **1.2.0 (5)**, the public bundle ID, and iOS 27.0.
  The executable is **arm64**.
- Both camera-adapted GMNet variants, AOT-GAN and Depth Anything V2 compiled models
  are present. English/Korean localizations and Velyn/model licenses are included.
- The archive contains no private photographs or PyTorch training checkpoints.
  Model integrity hashes are recorded in [model-integrity.json](../model-integrity.json).
- `Velyn-1.2.0-unsigned.ipa`: **113,484,219 bytes** (108.23 MiB).
- SHA-256: `3465be202973caf20216423225027fe2a6d8b9d9ac706a9cfdfc5a3e30f81e51`.

## Physical iPhone update

The paired iPhone 15 Pro was available. Its installed Velyn version was 1.0.0 (2).
The signed Release build was installed in place with the same local bundle ID and
signing identity, without uninstalling the app. `devicectl` reported installation
success, application launch success, and installed version **1.2.0 (5)** afterward.
No smoke-test or benchmark flags were passed to the user's installation.

This verifies update and launch. It does not verify the contents of the user's
library, HDR appearance on the physical display, sustained heat, or inference
latency. No personal device identifiers or signing settings are included here.
Local command outputs remain in ignored `.work/v1.2-*.json` and build logs.

## Public distribution

GitHub release assets are the unsigned IPA, `SHA256SUMS.txt`, and `INSTALL.md`.
The public package is separate from the personally signed device installation.
Other users must sign it for their device; AltStore Classic and Apple Configurator
paths have not been tested end to end for this release.

See [release notes](../Releases/v1.2.0.md), [app integration checks](hdr-camera-integration.md),
and [training comparison](hdr-gmnet-finetune-verification.md) for the model change,
known per-photo regressions and remaining acceptance gates. No C01–C10 or full
Lightroom parity claim is made by this release.
