# Velyn v1.1.0

This release improves SDR-to-HDR rendering, makes library actions easier to find, and replaces the README screenshots and editing examples with the current app.

## Changes

- **HDR tone protection adapts to scene contrast.** The previous curve suppressed useful gain in many compressed SDR photos. New predictions retain more of that gain while protecting darker tones.
- **Gain-map enlargement follows image edges** to reduce brightness bleeding across boundaries. The same gain still applies to all three color channels.
- **Existing edits stay compatible.** Predict the gain map again to apply the new processing. Your strength, maximum gain, and protection settings are retained. The app also identifies maps that no longer match the photo's edits.
- **Library selection and deletion are clearer.** Visible selection controls, album actions, reversible deletion, Undo, and Trash restoration make common tasks easier to find. Filter changes clear selections that are no longer visible.
- **The README has six new app screenshots**, a new synthetic photo, actual before/after exports, and downloadable HDR JPEG/HEIC examples.

The HDR model weights are unchanged. In a small audit of eight native-HDR/embedded-SDR pairs, equal-image mean luminance error fell from **0.441 EV to 0.372 EV (15.6%)**. Some images still differ substantially from native HDR, and correlation with the native gain pattern decreased on six samples. The change reduces brightness error; it does not recover the original scene's brightness or clipped detail. See the [measurements and limits](https://github.com/H4RUming/Velyn/blob/v1.1.0/Docs/Evidence/hdr-v11-quality.md).

## Download and install

**Requires iOS 27 or later and an arm64 iPhone.**

- Download **`Velyn-1.1.0-unsigned.ipa`** and sign it with your own Apple identity before installation. AltStore Classic is one documented option; Apple Configurator requires an already signed IPA.
- Read **`INSTALL.md`** below or the [installation guide](https://github.com/H4RUming/Velyn/blob/v1.1.0/Docs/Releases/INSTALL.md).
- Download `SHA256SUMS.txt` alongside the IPA and run `shasum -a 256 -c SHA256SUMS.txt` to verify it.

This is an unsigned build, not an App Store or TestFlight release. The public bundle ID is `com.h4ruming.velyn`. Keep the same bundle ID and signing identity when updating an existing installation.

**Keep separate copies of your originals.** Velyn's internal photo storage is excluded from system backups. Do not delete the app to update it without preserving your photos first.

## Validation and limits

- **75 engine tests pass**, including actual-model HDR export, neutral colors, legacy maps, adaptive tone protection, edge handling, and alpha preservation.
- The iOS 27 Simulator workflow passes prediction, JPEG/HEIC export, stale-map detection, setting preservation, and undo/redo checks.
- Simulator and signed iPhone builds succeed. The unsigned IPA is checked for version **1.1.0 (4)**, arm64 architecture, bundled models/localizations, archive integrity, and absence of a personal signature or provisioning profile.
- The physical iPhone was unavailable for a new installation or display check. AltStore and Configurator installation have not been tested end to end for this release. Broad camera/RAW coverage, sustained heat, and physical HDR display accuracy remain open.

All photo processing remains on the device. No model download was added to launch or import. Velyn's code is MIT-licensed; bundled models retain their respective licenses.
