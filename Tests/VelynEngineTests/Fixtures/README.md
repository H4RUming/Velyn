# Synthetic test fixture

`synthetic.dng` is generated entirely by `Scripts/make-test-dng.py`. It contains a 640×480 synthetic RGGB intensity ramp, orientation 6, and a minimal DNG 1.4 container. No camera photograph or third-party content is included. It is a CFA DNG, not Apple ProRAW.

Regenerate with `python3 Scripts/make-test-dng.py`. SHA-256 and preservation are checked at runtime against the actual input bytes. Dimensions smaller than 640×480 were not accepted as DNG by the installed macOS RAW decoder during fixture development; the retained fixture is the validated version.

JPEG/HEIC test images are created in temporary directories by ImageIO. All temporary images are removed by the tests.

`synthetic.webp` is generated by `Scripts/make-test-webp.py` with Pillow: a 128×96 RGB ramp with opaque and translucent halves, losslessly encoded. It contains no photographic content. Other raster fixtures (PNG/TIFF/GIF/BMP/AVIF/JPEG 2000 and animated GIF) are generated by `ImageFormatTests` using ImageIO.
