# Velyn

사진을 기기 안에서 처리하는 iPhone 편집기입니다. 가져온 원본은 바이트 그대로 보관하고 보정 기록을 별도로 저장합니다.

## 실행

1. Xcode 27에서 `Velyn.xcodeproj`의 Velyn scheme을 실행합니다. iOS 27이 필요합니다.
2. **사진 추가**에서 사진 보관함·파일·카메라를 선택합니다. DNG·HEIC·JPEG를 여러 장 가져올 수 있습니다.
3. 사진을 열고 아래 도구 목록을 좌우로 움직여 편집합니다.
4. **마스크**에서 영역을 지정하고 부분 보정하거나 **선택 영역 지우기**를 실행합니다.
5. **렌즈 흐림**에서 깊이를 분석하고 초점 거리·범위·흐림을 조절합니다.
6. 라이브러리의 **선택 → 작업**에서 별점·앨범·보정 붙여넣기·일괄 출력을 사용합니다.

실기기 설치 전 `Config/Local.xcconfig.example`을 `Config/Local.xcconfig`로 복사하고 개발 팀과 고유 Bundle ID를 입력하세요. 개인 설정은 Git에서 제외됩니다. 시뮬레이터는 서명 설정 없이 실행할 수 있습니다.

## 구현 기능

- 자동 톤·자동/스포이트 화이트밸런스, 히스토그램·클리핑 표시, 원본 해상도 영역 확인
- 밝기·색상·RGB 채널별 포인트 커브·8색 HSL·3영역 컬러 그레이딩
- 텍스처·명료도·안개·입자·선명도·일반/색 노이즈 감소
- 직접 자르기·회전·반전·수평·수동 원근/왜곡·색 번짐 완화
- 브러시 더하기/빼기·선형·방사형·밝기/색 범위·피사체·배경·탭 선택 마스크
- **요소 지우기**: 확대·이동, 브러시/선택 지우기, 명시적 실행으로 로컬 AOT-GAN 제거. **로컬 Depth Anything V2 깊이 흐림**
- 실행 취소/재실행·자동 저장·이름 있는 버전·Velyn 프리셋 가져오기/내보내기
- SDR 사진의 밝기 지도 예측·HDR 확장 강도/배율 조절, HDR 편집·gain map JPEG/HEIC, 원본 복사, 크기·색 공간·워터마크
- PNG·WebP·TIFF·GIF·BMP·AVIF·JPEG XL·JPEG 2000 가져오기, 최근 사진 선택 시트
- JPEG·PNG·HEIC·원본의 네 가지 저장, 실제 용량·출력 크기 안내
- P3 색역 확장 0–100%·따뜻한 색 계열 확장 완화·P3 미리보기 및 저장 (분석적 보간, NPU 미사용)
- 사진을 크게 보며 조절 항목 하나씩 선택, 드래그 중 최대 30회/초·768px, 완료 후 1536px 미리보기
- 다중 가져오기·일괄 보정/출력·앨범·별점·선별·복원 가능한 휴지통·로컬 사진 분류
- 수동 ISO·셔터·초점·노출 보정 카메라, 지원 기기에서 RAW/ProRAW 촬영 경로

각 기능의 동작 범위와 미구현 항목은 [기능 현황](Docs/professional-roadmap.md), 렌더·저장 규칙은 [편집 엔진](Docs/editor-features.md)에 기록합니다. Lightroom과 같은 처리 알고리즘이나 출력 품질을 보장하지 않습니다.

## 사진·모델의 처리 위치

앱 서버·사진 업로드·로그인·분석 SDK가 없습니다. 제거·깊이·HDR 밝기 지도 모델은 앱에 포함되며 네트워크 없이 추론합니다. Apple 탭 선택 모델은 사용자가 **선택 모델 준비**를 눌렀을 때만 내려받습니다. 실행·가져오기 시 자동 다운로드하지 않습니다.

PhotoKit 가져오기는 네트워크 접근을 끕니다. iCloud에만 있는 사진은 사진 앱에서 원본을 먼저 내려받아야 합니다. 파일 공급자의 다운로드는 시스템 설정을 따릅니다. 시스템 공유·저장 대상은 사용자가 선택합니다.

## 보관

원본과 메타데이터는 `Application Support/Velyn/Projects/<UUID>/`에 보관됩니다. 새 보정 출력은 GPS를 제거하며, **원본 내보내기**는 원래 메타데이터를 유지합니다. 앱 데이터는 시스템 백업에서 제외됩니다. 앱 삭제나 기기 분실에 대비해 원본을 별도로 보관하세요. 휴지통은 자동으로 비워지지 않습니다.

모델 출처·라이선스는 앱 설정과 `Velyn/Notices/`에 있습니다. 모델 파일을 포함하므로 소스 크기는 약 115MB 증가했습니다.

HDR 붉은 색조 수정: [실제 모델·기존 지도·저장 회귀 검증](Docs/Evidence/hdr-red-cast-verification.md).

HDR 보정 지표·중간톤 보호·실행 검증: [검증 기록](Docs/Evidence/hdr-diagnostics-verification.md).

SDR→HDR 구현과 검증 범위: [밝기 지도 검증](Docs/Evidence/gain-map-verification.md).
